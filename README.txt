《問道長生》v1.0.0 正式版

本版本收錄至飛升及仙界入口，使用獨立存檔與獨立排行榜。

開啟方式：雙擊 index.html，以瀏覽器開啟。

目前內容：
- 標題與創角畫面
- 男女與道號選擇
- 每 5 秒自動獲得修為
- 無上限離線收益
- 所有修為累積至公共修為池，由玩家自由選擇用途
- 左下靈修、右下體修獨立插圖按鈕，直接顯示升級需求
- 分層洞府背景、透明男女角色、前後雲霧、靈氣與雷劫特效
- 男女使用相同標準畫布與顯示高度，角色縮小以完整呈現靈氣擴散
- 男女各有三張完整人物換裝圖，創角時三選一；頭髮、人物與服裝在遊戲中不分層
- 右上選單提供回到標題、靜音／開啟音效與重置角色
- Steam／桌面寬螢幕使用完整橫向仙山場景，操作介面集中於畫面中央
- 手機版與桌面版分別調整人物、靈氣及雙修按鈕比例
- 靈修每十層渡劫
- 護脈丹、成功率、雷劫成功／失敗演出
- 自動保存於瀏覽器

若瀏覽器阻擋本機存檔，建議使用 Chrome 或 Edge。
